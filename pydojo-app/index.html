About the Python Debug Dojo

      
Small, focused Python bugs to diagnose and fix — IndexError, TypeError,
        mutable default arguments, off-by-one logic, and more. Read the broken program, run it,
        fix it, and Check your work. Stuck? Ask for an AI hint.

      
Static single-file app. Python executes locally in your browser via Pyodide.
        AI hints are routed through a proxy you configure under Stats → AI endpoint.
